# コミットメッセージ

- コミットメッセージは英語で記載する。
- コミット対象とした変更内容を示すメッセージをできるだけ簡潔な英語で書く。
- 変更箇所を示すプリフィクスをメッセージの先頭に追加する。
  - バックエンドの変更は `[backend]` を先頭に追加する
  - フロントエンドの変更は `[frontend]` を先頭に追加する
  - 管理画面の変更は `[admin]` を先頭に追加する
  - ドキュメントの変更は `[docs]` を先頭に追加する
  - リポジトリ設定の変更は `[repo]` を先頭に追加する
- 2種類以上同時に1つのコミットに入れる場合はカンマ区切りのプリフィクスを追加する
  - ex）フロントエンド、バックエンドの変更を同時に1つのコミットに含ませる場合は `[backend,frontend]` とする
